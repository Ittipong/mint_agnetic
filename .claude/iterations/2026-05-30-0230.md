### Issue 2 — Advisor income 2× (90,000 vs 45,000) ❌ → ✅ FIXED
**Investigation:**
- Reproduced `sum_income(2026-04-01, 2026-04-30, convert_to_thb=True)` locally → returned **90,000 (cnt=2)** but DB has **1 row, 45,000**
- Direct asyncpg fetch: 2 rows surfaced — `note='เงินเดือน'` at dates `2026-03-31T17:00 UTC` AND `2026-04-30T17:00 UTC`
- Both rows = `2026-04-01 00:00 +07` and `2026-05-01 00:00 +07` (Bangkok midnight on April 1 and May 1)
- asyncpg encodes Python `datetime.date(2026,4,1)` as a **timestamptz in client local TZ (Asia/Bangkok)** = `2026-03-31 17:00 UTC`. With PG session in UTC, the filter `t.date >= $2` matches `2026-03-31 17:00 UTC` → leaks the boundary row from March

**Root cause:** TZ mismatch between asyncpg client encoding (Bangkok) and PG session (UTC).

**Fix:** `src/agent/tools/codeact/db.py:get_pool` — added `server_settings={"timezone": "Asia/Bangkok"}` so PG session matches user-facing calendar.

**Verify:**
- Local repro w/ TZ=Asia/Bangkok → 1 row, 45,000 ✅
- Live curl after uvicorn reload: chat replied "รายได้ 45,000 บาท" (was 90,000) ✅

### Issue 3 — SSE narration + suggestions duplicate ❌ → ✅ FIXED
**Investigation:**
- Traced inner subgraph updates with FakeToolingModel calling `emit_suggestions`
- `react` node delta showed `emitted_blocks_this_turn` containing **2 identical blocks**
- Source: tools doing BOTH `state.setdefault("emitted_blocks_this_turn", []).append(block)` (in-place) AND returning `Command(update={"emitted_blocks_this_turn": [block]})`. LangGraph applied both — in-place mutation went into the channel + Command went through append_reducer → duplicate

**Fix:** removed in-place mutation in:
- `src/agent/tools/emit_suggestions.py:93`
- `src/agent/tools/wallet_required_cta.py:79`
- `src/agent/tools/codeact/__init__.py::_append_block` (turned into no-op)

Plus prompt rule: "On a TOOL ERROR retry: emit ONLY the retried tool_call — NO narration sentence" (cuts repeated `กำลังคำนวณ...`).

**Verify:**
- Unit repro: `node=react blocks_len=1` (was 2) ✅
- Live curl advisor: narration count = 2 (was 3) ✅
