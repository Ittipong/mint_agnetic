2 Text branch — Fast-path ก่อน แล้วค่อย ReAct

source: server.py::_text_graph_stream · fast_path.py · tiny_llm.py · เปิด/ปิด FAST_PATH_ENABLED

ทำไมต้องมี fast-path: ADD ง่าย ๆ ("ข้าวเที่ยง 120") ไม่ต้องใช้ LLM เต็ม — ลัดตรงไป propose_transaction ตัดเวลา ~3 วิ/turn. อะไรที่ไม่ใช่ ADD ง่าย ตกลง full ReAct
FAST PATH (text เท่านั้น)
Tier 0 · has_obvious_non_add_signal() — เจอสัญญาณ "ไม่ใช่ ADD" → fallback ReAct
Tier 1 · route_text_input() regex เป๊ะ → stream_fast_path_add() (ไม่เรียก LLM) ✅ return
Tier 2 · tiny-LLM classify_intent() (เฉพาะตอน heuristic พลาด):
ADD + complete → stream_fast_path_add() ✅ return
ADD + incomplete → Tier 3b stream_clarification_template() ✅ return
intent ≠ ADD → fallback ReAct
FastPathFailure ที่จุดใด ๆ → fallback ReAct (telemetry บันทึก error_kind)
▼ไม่ลัด → FULL GRAPH
FULL GRAPH path
1 · status_token "กำลังคิด..." (stream ทีละคำ)
2 · preamble — โมเดลถูก ๆ พูดเกริ่น 1 ประโยค เป็น status_token ชั่วคราว (ไม่มีตัวเลข → ขัดคำตอบจริงไม่ได้)
3 · build init_state {user_id, thread_id, messages:[user], default_wallet_sync_id}
4 · stream_chat(graph, state, config) → §3 + §5
5 · เก็บ blocks + answer → persist transcript (threads/messages repo, best-effort)
6 · empty-LLM fallback — ถ้าไม่มี answer/block เลย → ข้อความขออภัยภาษาไทย
