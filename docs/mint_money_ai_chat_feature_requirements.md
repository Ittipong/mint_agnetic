# Mint Money AI Chat Feature Requirements

## Purpose

เอกสารนี้ใช้เป็น checklist สำหรับ Product Owner เพื่อตรวจสอบว่า AI Chat Feature ของ Mint Money ครอบคลุมความต้องการหลักของผู้ใช้ในมุม **AI Personal Finance / AI Financial OS** แล้วหรือยัง

> Scope ของเอกสารนี้เน้น “สิ่งที่ user ควรถามได้ / AI ควรช่วยได้”  
> ไม่ลงรายละเอียดเชิง technical implementation

---

# 1. Financial Awareness
## ผู้ใช้ถามสถานะการเงินปัจจุบันได้

- [ ] ผู้ใช้สามารถถามภาพรวมการเงินปัจจุบันของตัวเองได้
- [ ] ผู้ใช้สามารถถามยอดเงินคงเหลือทั้งหมดได้
- [ ] ผู้ใช้สามารถถามรายรับรวมในช่วงเวลาที่ต้องการได้
- [ ] ผู้ใช้สามารถถามรายจ่ายรวมในช่วงเวลาที่ต้องการได้
- [ ] ผู้ใช้สามารถถาม cash flow สุทธิได้
- [ ] ผู้ใช้สามารถถามว่าเดือนนี้ใช้เงินไปเท่าไหร่ได้
- [ ] ผู้ใช้สามารถถามว่าเงินพอใช้ถึงสิ้นเดือนหรือไม่ได้
- [ ] ผู้ใช้สามารถขอ summary การเงินรายวัน / รายสัปดาห์ / รายเดือนได้
- [ ] ผู้ใช้สามารถถามว่าสถานะการเงินตอนนี้ดีขึ้นหรือแย่ลงได้
- [ ] ผู้ใช้สามารถถามรายการใช้จ่ายล่าสุดได้

---

# 2. Spending Analysis
## ผู้ใช้เข้าใจพฤติกรรมการใช้เงินของตัวเองได้

- [ ] ผู้ใช้สามารถถามว่าใช้เงินกับหมวดไหนมากที่สุดได้
- [ ] ผู้ใช้สามารถถามค่าใช้จ่ายแยกตามหมวดหมู่ได้
- [ ] ผู้ใช้สามารถถามค่าใช้จ่ายเฉพาะหมวด เช่น อาหาร เดินทาง ช้อปปิ้ง ได้
- [ ] ผู้ใช้สามารถถามว่าเดือนนี้ใช้เงินมากกว่าเดือนก่อนหรือไม่ได้
- [ ] ผู้ใช้สามารถถามรายการใช้จ่ายที่สูงผิดปกติได้
- [ ] ผู้ใช้สามารถถามว่าค่าใช้จ่ายใดเกิดซ้ำบ่อยได้
- [ ] ผู้ใช้สามารถถามว่าเงินหายไปกับอะไรได้
- [ ] ผู้ใช้สามารถถามว่ามีรายจ่ายที่ไม่จำเป็นหรือไม่ได้
- [ ] ผู้ใช้สามารถถามว่าหมวดไหนควรลดก่อนเป็นอันดับแรกได้
- [ ] ผู้ใช้สามารถถาม spending trend ในช่วงเวลาต่างๆ ได้

---

# 3. Financial Diagnosis
## AI ช่วยหาปัญหาทางการเงินให้ผู้ใช้ได้

- [ ] ผู้ใช้สามารถถามว่าปัญหาการเงินหลักของตัวเองคืออะไรได้
- [ ] ผู้ใช้สามารถถามว่าทำไมเงินหมดเร็วได้
- [ ] ผู้ใช้สามารถถามว่าทำไมเก็บเงินไม่ได้ได้
- [ ] ผู้ใช้สามารถถามว่ามีพฤติกรรมใช้เงินเกินตัวหรือไม่ได้
- [ ] ผู้ใช้สามารถถามว่าจุดรั่วเงินอยู่ตรงไหนได้
- [ ] ผู้ใช้สามารถถามว่าค่าใช้จ่ายไหนทำให้เงินไม่เหลือได้
- [ ] ผู้ใช้สามารถถามว่า cash flow มีปัญหาหรือไม่ได้
- [ ] ผู้ใช้สามารถถามว่าอะไรเป็น root cause ของปัญหาเงินได้
- [ ] ผู้ใช้สามารถถามว่าพฤติกรรมการเงินแบบไหนควรระวังได้
- [ ] AI ต้องสามารถอธิบายปัญหาแบบไม่ตัดสินหรือทำให้ผู้ใช้รู้สึกผิด

---

# 4. Financial Problem Solving
## AI ช่วยผู้ใช้แก้ปัญหาทางการเงินได้

- [ ] ผู้ใช้สามารถขอแผนแก้ปัญหาเงินไม่พอใช้ได้
- [ ] ผู้ใช้สามารถขอแผนลดรายจ่ายได้
- [ ] ผู้ใช้สามารถขอแผนหยุดเงินเดือนชนเดือนได้
- [ ] ผู้ใช้สามารถขอแผนเริ่มเก็บเงินได้
- [ ] ผู้ใช้สามารถขอคำแนะนำว่าควรเริ่มแก้จากจุดไหนก่อนได้
- [ ] ผู้ใช้สามารถขอ action plan รายสัปดาห์ได้
- [ ] ผู้ใช้สามารถขอแผนฟื้นตัวทางการเงินแบบ step-by-step ได้
- [ ] ผู้ใช้สามารถถามว่าถ้ามีเงินจำกัดควรจ่ายอะไรก่อนได้
- [ ] ผู้ใช้สามารถขอคำแนะนำที่เหมาะกับสถานะการเงินจริงของตัวเองได้
- [ ] AI ต้องให้คำตอบที่ทำตามได้จริง ไม่ใช่คำแนะนำกว้างๆ

---

# 5. Financial Planning
## AI ช่วยผู้ใช้วางแผนการเงินได้

- [ ] ผู้ใช้สามารถขอวางแผนงบประมาณรายเดือนได้
- [ ] ผู้ใช้สามารถขอวางแผนเก็บเงินตามเป้าหมายได้
- [ ] ผู้ใช้สามารถขอวางแผนซื้อของชิ้นใหญ่ได้
- [ ] ผู้ใช้สามารถขอวางแผนซื้อรถได้
- [ ] ผู้ใช้สามารถขอวางแผนซื้อบ้านได้
- [ ] ผู้ใช้สามารถขอวางแผนแต่งงานได้
- [ ] ผู้ใช้สามารถขอวางแผนครอบครัวหรือมีลูกได้
- [ ] ผู้ใช้สามารถขอวางแผนเงินฉุกเฉินได้
- [ ] ผู้ใช้สามารถขอวางแผนเกษียณเบื้องต้นได้
- [ ] AI ต้องช่วยแตกเป้าหมายใหญ่ให้เป็นแผนรายเดือนหรือรายสัปดาห์ได้

# 6. Debt Management
## AI ช่วยผู้ใช้จัดการหนี้ได้

- [ ] ผู้ใช้สามารถถามยอดหนี้รวมทั้งหมดได้
- [ ] ผู้ใช้สามารถถามหนี้แต่ละก้อนแยกตามประเภทได้
- [ ] ผู้ใช้สามารถถามว่าหนี้ไหนน่ากังวลที่สุดได้
- [ ] ผู้ใช้สามารถถามว่าควรจ่ายหนี้ก้อนไหนก่อนได้
- [ ] ผู้ใช้สามารถขอแผนปลดหนี้ได้
- [ ] ผู้ใช้สามารถถามผลกระทบของการจ่ายขั้นต่ำได้
- [ ] ผู้ใช้สามารถถามว่าดอกเบี้ยรวมเท่าไหร่ได้
- [ ] ผู้ใช้สามารถถามว่าถ้าโปะเพิ่มจะหมดหนี้เร็วขึ้นแค่ไหนได้
- [ ] ผู้ใช้สามารถขอเปรียบเทียบวิธี snowball และ avalanche ได้
- [ ] AI ต้องช่วยให้ผู้ใช้รู้สึกว่าหนี้ยังแก้ไขได้ ไม่ทำให้หมดกำลังใจ

---

# 7. Cashflow Optimization
## AI ช่วยให้ผู้ใช้บริหารเงินให้พอใช้ได้

- [ ] ผู้ใช้สามารถถามว่าเดือนนี้ควรใช้เงินวันละเท่าไหร่ได้
- [ ] ผู้ใช้สามารถถามว่าเงินที่เหลือควรแบ่งอย่างไรได้
- [ ] ผู้ใช้สามารถถามว่าควรลดรายจ่ายหมวดไหนเพื่อให้พอถึงสิ้นเดือนได้
- [ ] ผู้ใช้สามารถถามว่ามี bill หรือภาระจ่ายอะไรที่กำลังจะมาถึงได้
- [ ] ผู้ใช้สามารถถามว่าถ้าใช้เงินแบบนี้ต่อไปจะเหลือเท่าไหร่ได้
- [ ] ผู้ใช้สามารถขอแผนประคองเงินถึงวันเงินเดือนได้
- [ ] ผู้ใช้สามารถขอคำแนะนำเมื่อต้องเลือกจ่ายหลายอย่างพร้อมกันได้
- [ ] AI ต้องช่วย prioritize ค่าใช้จ่ายจำเป็นก่อนค่าใช้จ่ายไม่จำเป็นได้

---

# 8. Budget Management
## AI ช่วยติดตามและปรับงบประมาณได้

- [ ] ผู้ใช้สามารถถามสถานะ budget แต่ละหมวดได้
- [ ] ผู้ใช้สามารถถามว่างบหมวดไหนใกล้เกินได้
- [ ] ผู้ใช้สามารถถามว่างบหมวดไหนเกินแล้วได้
- [ ] ผู้ใช้สามารถขอปรับ budget ให้เหมาะกับพฤติกรรมจริงได้
- [ ] ผู้ใช้สามารถถามว่างบที่ตั้งไว้ realistic หรือไม่ได้
- [ ] ผู้ใช้สามารถขอ budget plan สำหรับเดือนหน้าได้
- [ ] ผู้ใช้สามารถถามว่าเดือนนี้ควรคุมหมวดไหนเป็นพิเศษได้
- [ ] AI ต้องอธิบาย budget แบบเข้าใจง่ายและไม่ทำให้ผู้ใช้รู้สึกถูกบังคับ

# 9. Goal & Saving Management
## AI ช่วยผู้ใช้เก็บเงินตามเป้าหมายได้

- [ ] ผู้ใช้สามารถสร้างเป้าหมายการเงินผ่านการคุยกับ AI ได้
- [ ] ผู้ใช้สามารถถามความคืบหน้าของเป้าหมายได้
- [ ] ผู้ใช้สามารถถามว่าต้องเก็บเดือนละเท่าไหร่เพื่อถึงเป้าหมายได้
- [ ] ผู้ใช้สามารถถามว่าเป้าหมายนี้เป็นไปได้จริงหรือไม่ได้
- [ ] ผู้ใช้สามารถขอปรับแผนเมื่อเก็บเงินไม่ทันได้
- [ ] ผู้ใช้สามารถถามว่าควรลดอะไรเพื่อให้ถึงเป้าหมายเร็วขึ้นได้
- [ ] ผู้ใช้สามารถขอ motivation หรือ encouragement เพื่อทำตามเป้าหมายได้
- [ ] AI ต้องช่วยทำให้เป้าหมายการเงินรู้สึกจับต้องได้และไม่ไกลเกินไป

# 10. Financial Decision Assistant
## AI ช่วยผู้ใช้ตัดสินใจเรื่องเงินได้

- [ ] ผู้ใช้สามารถถามว่าควรซื้อของชิ้นหนึ่งหรือไม่ได้
- [ ] ผู้ใช้สามารถถามว่าควรผ่อนหรือซื้อสดได้
- [ ] ผู้ใช้สามารถถามว่าควรซื้อรถตอนนี้หรือไม่ได้
- [ ] ผู้ใช้สามารถถามว่าควรย้ายงานหรือลาออกได้ไหมในมุมการเงินได้
- [ ] ผู้ใช้สามารถถามว่าควรรับภาระรายจ่ายใหม่หรือไม่ได้
- [ ] ผู้ใช้สามารถขอเปรียบเทียบทางเลือกหลายทางได้
- [ ] ผู้ใช้สามารถถามผลกระทบระยะสั้นและระยะยาวของการตัดสินใจได้
- [ ] AI ต้องช่วยให้ผู้ใช้เห็น trade-off ไม่ใช่แค่ตอบว่า “ควร” หรือ “ไม่ควร”

# 11. Financial Simulation
## AI ช่วยจำลองอนาคตทางการเงินได้

- [ ] ผู้ใช้สามารถถามว่าใช้เงินแบบนี้ต่อไปอีก 3 เดือนจะเป็นอย่างไรได้
- [ ] ผู้ใช้สามารถถามว่าถ้าลดค่าใช้จ่ายบางหมวดจะเหลือเงินเพิ่มเท่าไหร่ได้
- [ ] ผู้ใช้สามารถถามว่าถ้าเพิ่มรายได้จะเปลี่ยนสถานะการเงินอย่างไรได้
- [ ] ผู้ใช้สามารถถามว่าถ้าโปะหนี้เพิ่มจะหมดหนี้เมื่อไหร่ได้
- [ ] ผู้ใช้สามารถถามว่าถ้าเริ่มเก็บเงินวันนี้จะถึงเป้าหมายเมื่อไหร่ได้
- [ ] ผู้ใช้สามารถขอจำลองหลาย scenario เพื่อเปรียบเทียบได้
- [ ] AI ต้องแยกให้ชัดเจนว่าอะไรคือข้อมูลจริง และอะไรคือการประมาณการ

- [ ] ผู้ใช้สามารถถามว่าต้องมีรายได้เพิ่มเท่าไหร่ถึงจะพอใช้ได้
- [ ] ผู้ใช้สามารถขอไอเดียเพิ่มรายได้ที่เหมาะกับตัวเองได้
- [ ] ผู้ใช้สามารถถามว่า side hustle แบบไหนเหมาะกับสถานะของตัวเองได้
- [ ] ผู้ใช้สามารถถามว่าควรเพิ่มรายได้หรือควรลดรายจ่ายก่อนดีได้
- [ ] ผู้ใช้สามารถขอแผนเพิ่มรายได้แบบค่อยเป็นค่อยไปได้
- [ ] AI ต้องไม่แนะนำวิธีหารายได้ที่เสี่ยงเกินไปหรือไม่เหมาะกับผู้ใช้

- [ ] ผู้ใช้สามารถถามแนวคิดการลงทุนเบื้องต้นได้
- [ ] ผู้ใช้สามารถถาม DCA คืออะไรและเหมาะกับตัวเองไหมได้
- [ ] ผู้ใช้สามารถถามว่าควรแบ่งเงินออมและลงทุนอย่างไรได้

Mint Money AI ไม่ควรเป็นแค่ chatbot ที่ตอบคำถามการเงิน
